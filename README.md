# 课表自动同步

> **本项目仅为本人自用。**
>
> 不是通用产品，也没有做成"支持所有学校"的打算——代码里不含多厂商适配层，
> 默认值也是按我自己的学校填的（换学校需要改配置甚至改代码）。
>
> 之所以公开，一是仓库必须公开才能用 jsDelivr 免费托管订阅文件，二是我自己
> 也会持续用到。**如果你有更简单/更稳的方案，非常欢迎提 Issue 或在 Discussion 里告诉我。**

把正德职业技术学院教务系统的课表，变成一条**可订阅的日历链接**。
手机日历订阅一次，之后课表变了会自动更新，不用开电脑、不用装 App、不用自己的服务器。

---

## 订阅地址

**推荐（GitHub Pages，缓存 10 分钟）：**

```
https://huey-iii.github.io/course-calendar/calendar.ics
```

**备用（jsDelivr CDN，缓存 12 小时）：**

```
https://fastly.jsdelivr.net/gh/Huey-iii/course-calendar@main/calendar.ics
```

手机端添加方式：

> 设置 → 日历 → 账户 → 添加账户 → 其他 → **添加已订阅的日历** → 粘贴上面的地址

两个地址指向同一个文件，订一个即可；也可以两个都订，互为备份。

---

## 工作原理

```
GitHub Actions（每天 8:00–22:00，每小时一次）
      ↓ 登录教务系统
      ↓ 抓取课表 + 调课记录
      ↓ 生成 calendar.ics
      ↓ 提交回本仓库
      ↓
jsDelivr CDN / GitHub Pages
（免费、HTTPS、无需服务器）
      ↓
手机日历订阅
```

全程跑在 GitHub 的服务器上，**不依赖任何一台个人电脑开机**，也没有自己的服务器。

---

## 已知限制（如实记录）

| 限制 | 说明 |
|---|---|
| **更新有延迟** | Pages 缓存 10 分钟。备用的 jsDelivr 对分支地址缓存 12 小时，且实测 `purge` 刷不掉。再加上手机端约 12 小时的轮询：**Pages 最晚约 12 小时、jsDelivr 最晚约 24 小时**可见 |
| 依赖 CDN 可达性 | `cdn.jsdelivr.net` 在部分网络下会 TLS 握手失败，改用 `fastly` / `gcore` 节点即可 |
| 只支持正方 | 登录流程按正方教务系统 V5 写死；强智 / 青果 / URP 用不了 |
| 需要公网可访问 | 只能在校园网访问的教务系统跑不通 |
| 不支持验证码 | 有验证码或走 CAS 统一认证的学校需要另外改造 |

## 配置

在 `Settings → Secrets and variables → Actions` 里设置：

### Secrets（必填）

| 名称 | 说明 |
|---|---|
| `JW_USERNAME` | 教务系统学号 |
| `JW_PASSWORD` | 教务系统密码 |
| `JW_BASE_URL` | 教务系统地址，如 `https://jwxt.example.edu.cn` |

### Variables

| 名称 | 默认值 | 说明 |
|---|---|---|
| `SEMESTER_START` | `2026-09-07` | 第 1 周的**周一**日期 |
| `SCHOOL_NAME` | `正德职业技术学院` | 日历里显示的名称 |
| `SUBSCRIBE_HOST` | 空 | 可选。填了才会额外推送到自建订阅服务 |

## 安全阀

若抓取到的事件数低于 `MIN_EVENTS`（默认 60），脚本会**主动中止、不覆盖** `calendar.ics`，
避免把线上文件刷成残缺版本。

推送类步骤也都显式校验 HTTP 状态码——**失败会直接让 workflow 变红**，
不会出现"流水线绿灯、手机却没更新"的静默故障。

## 调课标记

| 标记 | 含义 |
|---|---|
| 🔴 | 换教室 |
| 🔵 | 调时间 / 调周次 |
| 🟠 | 换教师 |

标记追加在事件标题末尾，详细变化写在事件备注最后一行。
整学期性的变更（如换教师）不标记，只标临时调整。

## 文件结构

| 文件 | 作用 |
|---|---|
| `scraper.py` | 登录正方教务系统、抓取 `kbList`、解析调课记录 |
| `ical_gen.py` | 课表 → `.ics`，含作息表映射与调课标记 |
| `zf_rsa.py` | 正方登录用的 RSA 加密（移植自开源实现，见下） |
| `sync.py` | Actions 里的入口：读环境变量 → 抓取 → 生成 → 安全阀 |
| `.github/workflows/sync.yml` | 定时任务定义 |
